# Презентация Team 040

Интерактивная версия: `index.html` (14 слайдов, 1920×1080, масштабируется под окно).
Живая 3D-шахта на слайдах 1, 3 и 9 — тот же `team/ui/public/models/mine-art/env.glb`
и актёры пульта, three.js из `team/ui/public/vendor/three/`, шрифты из
`team/ui/public/fonts/`. Сеть не нужна.

```sh
python -m http.server 8000          # из корня репозитория
# http://127.0.0.1:8000/team/presentation/index.html
```

Управление: `→` `↓` `PageDown` пробел — дальше; `←` `↑` `PageUp` — назад; `Home` / `End`;
колесо; свайп; точки на шкале глубины справа; `#N` в адресе; `F` — полный экран.
При системной настройке «уменьшить движение» переходы мгновенные, камера не летает.
Без WebGL вместо живой шахты показан снимок `img/mine-overview.jpg`.

`presentation.pdf` в корне репозитория собирается из этой страницы в headless Chrome
(SwiftShader), по странице 16:9 на слайд, текст выделяется:

```sh
python team/presentation/tools/render_pdf.py
```

Видеозапись прохода по слайдам (75 с, 1280×720) в репозиторий не входит; она доступна у Команды по запросу.

Снимки пульта в `img/ui-*.jpg` сделаны на тестовом сервере интерфейса (фикстуры
сценария «Рост нестабильности»), не на стенде с платформой.
