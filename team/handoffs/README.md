# Передача задач между агентами

Здесь лежат задания (briefs), которые AI-агенты Команды передавали друг другу: задание на интерфейс, задание на модель погрузочно-доставочных машин (ПДМ), предложение расширения контракта и план интерфейса под него.
Документы сохранены как запись того, как работа делилась между агентами. Они не входят в описание решения и не описывают итоговое состояние: актуальные данные и контракт смотрите в `team/CONTRACT.md` и `SUBMISSION.md`.
